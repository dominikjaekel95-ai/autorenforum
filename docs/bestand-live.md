**Grenzen der Erhebung**

- Ob eine Weiterleitung mit 301 oder 302 antwortet, zeigt der Browser nicht an. Bei Weiterleitungen stehen deshalb das Endziel und dessen Status da.
- Links mit `http://` blockiert der Browser auf einer https-Seite. Was diese Adressen liefern, steht in Abschnitt 6.

## 6. Hostvarianten und http-Links

Geprüft am 08.11.2026 im Browser: Adresse aufgerufen, Endadresse abgelesen.

| Aufgerufen | Endadresse |
|---|---|
| `http://autorenforum-berlin.de/` | `https://autorenforum-berlin.de/` |
| `http://www.autorenforum-berlin.de/` | `https://autorenforum-berlin.de/` |
| `https://www.autorenforum-berlin.de/` | `https://autorenforum-berlin.de/` |
| `https://autorenforum-berlin.de/` | bleibt, Status 200 |

- Die eine Hostvariante ist damit **https ohne www**.
- Statuscodes und die Zahl der Schritte zeigt der Browser nicht an.
- Die Weiterleitung von www auf die Domain ohne www macht der Server. Ein Browser wechselt den Host nicht von sich aus.
- Bei http ist das nicht sicher: Der Server sendet keinen HSTS-Header, aber Chromium stuft http-Adressen auch selbst auf https hoch. Prüfen lässt sich das von einem Rechner mit freiem Netz mit `curl -sI http://autorenforum-berlin.de/` und `curl -sI https://www.autorenforum-berlin.de/`.
